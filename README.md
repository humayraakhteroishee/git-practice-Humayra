# Git Practice Project

**Name: Humayra Akhter Oishee**

### What this project does
-----
The Objective of this project is to create and manage a GitHub. It is a practice to create repository, use Git locally, make multiple commits, work with branches, merge branches and push code to GitHub.

### Faundamentals 
----
- Creating a Public GitHub Repository
- Initialize Local Project
- making multiple commits and their usage
- Creating and Working on a Branch
- Switching Back and Merge the branches
- Connecting to the github web

### Git-bash Commands
------
- git config --global user.name "username"
- git config --global user.email "user email id"
- mkdir   
- cd
- git init
- touch
- tree (to use tree, "winget install GnuWin32.Tree" needs to be installed )
- git status
- git add .
- git commit -m "msg"
- git log --oneline
- git checkout -b 
- git branch
- git merge
- git branch --merged
- git branch -d
- git remote add origin https://... .git
- git branch -M main
- git push -u origin main
